1. RIGHT-CLICK this zip -> "Extract All" (do NOT open StudyVault.html from inside the zip).
2. Open StudyVault.html in Google Chrome or Microsoft Edge (not Firefox, Safari or Brave).
3. Click "Choose folder" and pick your main folder (e.g. Documents\StudyVault).
4. Next time, click "Reconnect folder" once.
If something fails, a message appears at the bottom-right - send me that text.

NEW: "Visualize What You Study" holds LINKS (e.g. your GitHub Pages visualizations), not files. Click "Open visualization" and it opens directly in a new tab.
Every link (visualizations, GitHub repositories, bookmarks) is also saved in its folder as a small .html shortcut file - double-click it and Chrome opens the link.
Uploaded files (PDF, ZIP, video, images...) are saved exactly as they were uploaded, in the same format.

Start-up: every time StudyVault opens it shows the "Welcome to Study Vault - Built by Vinit M. Shimpi" landing screen, then asks you to connect your folder and enter your name. Your name is shown in the welcome title and can be changed any time in Dashboard > profile > Edit profile.
