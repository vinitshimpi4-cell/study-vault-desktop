INSTALL STUDYVAULT AS A REAL APP (Chrome or Edge, no Node.js)

Option A - easiest, nothing to run on your PC
1. Upload the contents of the "pwa" folder to a GitHub repo and turn on GitHub Pages (Settings > Pages > main / root).
2. Open the https://<you>.github.io/<repo>/ link in Chrome or Edge.
3. Click the install icon at the right end of the address bar (or menu > Cast, save and share > Install page as app, in Edge: Apps > Install this site as an app).
4. StudyVault now has its own window, Start-menu entry and taskbar icon. Pin it if you like.

Option B - local
1. Install Python from python.org (tick "Add to PATH"), then double-click INSTALL-as-app-local.bat.
2. Chrome/Edge opens http://localhost:8765/ - click the install icon in the address bar.
3. The installed app opens http://localhost:8765, so the .bat must be running to launch it. Prefer Option A for daily use.

Option C - real standalone program (.exe)
Install Node.js, run START-StudyVault.bat, or "npm run dist" to build an installer.

First use: click "Choose folder" and pick your StudyVault folder; later click "Reconnect folder".
